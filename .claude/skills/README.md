# Project skills

Seven skills from [Jeffallan/claude-skills](https://github.com/Jeffallan/claude-skills)
(v0.4.18, commit 1be15d8, MIT; see `LICENSE-claude-skills`), copied unchanged:

| Skill | Use it for |
|-------|-----------|
| `game-developer` | Game systems, pooling, state machines, shaders, performance (written for Unity/Unreal; apply the ideas to Godot/GDScript) |
| `debugging-wizard` | Reproduce, isolate, hypothesise, fix, add a regression test |
| `code-reviewer` | Structured review reports |
| `test-master` | Test strategy and test writing (this project's tests use `harness/test_case.gd`, not Jest/pytest) |
| `code-documenter` | Doc comments and guides |
| `the-fool` | Devil's advocate: pre-mortems, red-teaming a design |
| `prompt-engineer` | Writing and evaluating LLM prompts |

The rest of the 67 in that repo target other stacks and were left out. To update, re-copy a
skill's folder from a newer release of the repo.
